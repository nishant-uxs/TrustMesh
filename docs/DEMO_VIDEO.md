# TrustMesh demo video (1–2 min)

## Goal

Show a real Freighter-signed Testnet transaction and the six-contract architecture.

## Prep

1. Freighter → **Testnet** + Friendbot funding
2. `cd frontend && npm run dev`
3. Screen recorder ready (Loom / OBS)

## Shot list (~90 seconds)

| Time | Action |
|---|---|
| 0:00–0:15 | Landing — say “TrustMesh, business trust on Stellar” → Open app |
| 0:15–0:30 | Connect Wallet → Freighter → show address |
| 0:30–0:45 | Settings — flash all 6 Testnet contract IDs |
| 0:45–1:20 | Organizations → register → wallet **sign** → success + Expert link |
| 1:20–1:45 | Open tx on Stellar Expert (optional 2nd tx) |
| 1:45–2:00 | Activity / Dashboard → end card with repo URL |

## Voiceover

> TrustMesh lets businesses register on Stellar, form verified relationships, leave reviews, and build an on-chain reputation score — six cooperating Soroban contracts, live on Testnet.
